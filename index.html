01 / INTRODUCTION

About me.

I turn complex security signals into clear, actionable decisions.

I'm Pahan De Silva, a Sri Lanka-based Security Engineer working across multiple client environments for an Australian managed security services provider. My day-to-day work spans endpoint, identity, email, network, and cloud security investigations.

I investigate EDR/XDR and SIEM alerts, hunt for threats with KQL and YARA-L, assess vulnerabilities and exposure, and coordinate practical remediation with engineering teams. I'm particularly interested in improving SOC efficiency with agentic AI while keeping decisions and incident response analyst-validated.

I have worked with Microsoft Defender XDR, CrowdStrike Falcon, Sentinel, Google SecOps (Chronicle), Fortinet, ThreatLocker, NinjaOne, and the wider Microsoft 365 security ecosystem.
