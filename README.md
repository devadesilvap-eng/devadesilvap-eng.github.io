# Pahan De Silva - Portfolio Website

A responsive dark terminal-style cybersecurity portfolio, inspired by the structure of the referenced portfolio but created as an original design and personalized for Deva Pahan De Silva.

## Deploy to GitHub Pages

1. On GitHub, create a **public** repository named exactly `devadesilvap-eng.github.io`.
2. Upload **the contents of this folder** (`index.html`, `assets/`, `README.md`) to the repository root, on the `main` branch.
3. Under **Settings → Pages**, select **Deploy from a branch**, **main**, **/(root)** and **Save**.
4. Visit https://devadesilvap-eng.github.io/ after GitHub finishes deployment.

The GitHub project cards use GitHub's public API at page-load, so new public repositories appear automatically (up to 6). This site does not expose private projects or require tokens.

## Edit details

- `index.html`: biography, experience, certifications, external links.
- `assets/style.css`: color palette, layout and typography.
- `assets/main.js`: typewriter rotation and GitHub repository cards.

No build step is required. Open `index.html` directly to preview it locally (the live GitHub cards require internet access).
